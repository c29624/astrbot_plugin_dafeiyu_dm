# astrbot_plugin_dafeiyu_dm · 主动私聊

让 bot **主动来找你说话**：晨起一句、睡前晚安、白天随机想念——她睡着的时候绝不打扰。

## 三类触发（各自带开关）

| 触发 | 时机 | 内容基调 |
|---|---|---|
| **晨起问候** | 醒来后 5~30 分钟 | 带着刚醒的劲儿来一句 |
| **睡前晚安** | 今晚入睡点前 10 分钟内 | 困困地说句晚安再睡 |
| **随机想念** | 白天清醒期每天 N 次（默认 2）随机时刻 | "突然想起你"式的一两句话 |

## 特性

- **默认零配置可用**：发送对象留空 = 自动使用 AstrBot 管理员列表（`admins_id`）；要发给指定的人就填 QQ 列表
- **作息联动**（灵魂）：直接读 [astrbot_plugin_dafeiyu_sleep](https://github.com/c29624/astrbot_plugin_dafeiyu_sleep) 的状态文件——她睡着绝不主动发消息；晨起/睡前钩子跟着真实作息走；到点碰上半梦半醒（临时清醒）会自动顺延。**没装睡觉插件也能跑**（退化为纯时间窗模式）
- **内容现场生成**：带现用人设调 LLM 生成（提示词模板可改，变量 `{who}`=收信人称呼），失败/超时回落语料池
- **频率保险（风控友好）**：每日总量上限（默认 4 条）、随机消息最短间隔（默认 2 小时）；晨起/睡前是作息事件不受间隔限制但仍计入总量
- **跨重启可靠**：当日计划与计数落盘，重启不重发、不丢计划
- 群聊完全不受影响

## 配置速览

| 组 | 字段 | 默认 | 说明 |
|---|---|---|---|
| 基础 | dm_enabled | `true` | 插件总开关 |
| 基础 | dm_targets | `[]` | 发送对象 QQ；留空=**全部配置文件管理员的并集**（多配置文件/多管理员场景都覆盖），填了就只发这些人 |
| 基础 | dm_platform | `""` | 平台 ID；留空=自动发现（多平台时各自发它自己的管理员） |
| 基础 | dm_owner_alias | `对方` | 全局称呼（提示词变量 {who}） |
| 基础 | dm_alias_map | `[]` | 按 QQ 配称呼：`"10001=主人"`——多收信人各叫各的 |
| 基础 | dm_with_context | `true` | 生成时附带该会话最近聊天记录（接话茬） |
| 基础 | dm_context_count | `10` | 附带条数（3~40） |
| 基础 | dm_respect_sleep | `true` | 作息联动（读睡觉插件状态：睡着不发；没装则当白天跑） |
| 触发 | dm_morning_on / dm_night_on | `true` | 晨起/睡前开关 |
| 触发 | dm_random_count | `2` | 随机想念次数/天，0=关 |
| 触发 | dm_window_start / dm_window_end | `10:00`~`22:00` | 随机想念时间窗（HH:MM） |
| 触发 | dm_min_gap_hours | `2.0` | 随机消息与上一条的最短间隔 |
| 触发 | dm_daily_cap | `4` | 每日总量上限（建议 ≤4，防风控） |
| 触发 | dm_seg_enabled | `true` | 拟人分段发送（按句切分，条间隔=打字时间） |
| 模板 | dm_morning_template | 见 hint | 晨起提示词（{who}） |
| 模板 | dm_night_template | 见 hint | 睡前提示词（晚安只是选项，语气随聊天氛围） |
| 模板 | dm_night2_template | 见 hint | 已道过晚安时的收尾话提示词 |
| 模板 | dm_random_template | 见 hint | 随机想念提示词 |
| 模板 | dm_makeup_night_template | 见 hint | 补发晚安提示词 |
| 模板 | dm_fallback_pool | 5 句 | LLM 失败回落语料 |

提示词统一原则：只给任务与状态（刚醒/要睡/突然想起），措辞和语气让模型按聊天上下文自己定——不锁腔调。

另有**补发通道**（非面板配置）：往插件数据目录写 `makeup.json`（`{"kind": "night"|"morning"|"random"}`），30 秒内补发一条。

## 实现说明

30 秒一次的 tick 循环：读睡觉插件 `sleep_state.json`（存在性+phase），晨起按 `wake_at` 延迟 5~30 分钟计划时刻（持久化防漂移）、睡前按 `sleep_window[0]` 前 10 分钟窗触发、随机想念每天凌晨在时间窗内抽时刻排程（睡着顺延半小时、出窗作废）。发送走 `context.send_message(umo)`，umo = `平台ID:FriendMessage:QQ`。内容生成同睡觉插件告别语套路：persona_manager 取现用人设 + provider.text_chat 超时回落。

## 更新记录

- **1.3.1** 新增 `/主动私聊工具`：列出所有已注册工具（所属插件·工具名·说明）——用户不用再猜白名单该填什么
- **1.3.0** 工具调用上线：三类触发独立配置（`dm_tools_{morning,night,random}_{on,names}`），走框架 `tool_loop_agent`+合成事件，白名单空=全部工具，默认全关；失败回落纯文本，产物照常分段+归档
- **1.2.6** 主动消息**归档对话历史**：每条发出的主动消息追加进对应会话的历史（user 侧只放极简系统标记，不污染上下文）——否则主对话里"她从没说过这句"，后续回复会失忆般重复报到（实测：晨起 DM 问完好，冲刷轮又完整演一遍"刚醒"）
- **1.2.5** 晨起问候**防重复**：若某目标用户在她醒来后已先发过消息（晨间冲刷已带出"刚醒读夜间消息"的演出），该目标的晨起主动消息自动跳过——不再"用户先开口聊上了、她又主动来一遍早上好"；按目标各查各
- **1.2.4** 其余四条提示词（晨起/晚安/随机/补发）同款放开：只给任务与状态（刚醒/要睡/突然想起），措辞与语气一律"按你们的相处和最近聊天的氛围自己定"——晚安也只作为选项之一，不锁"困困的"这类指定腔调；schema 补 `dm_makeup_night_template` 字段
- **1.2.3** 收尾话提示词放开：去掉例句锚定（"我也去睡啦"这类会把语气框死），改为"按你们刚才聊天的氛围收尾，语气跟着氛围走"——平常聊平常收、腻歪着收尾就接着那个劲儿；模型自己看着上下文定分寸
- **1.2.2** 已道过晚安时**改发收尾话而非跳过**：睡前主动消息遇"她已在聊天里说过晚安"，不再重复晚安、也不静默，改用 `dm_night2_template` 生成"我也去睡啦"这类收尾话——消息照到、不穿帮、不重复
- **1.2.1** 睡前晚安**防重复**：若她在该会话最近的聊天里已经说过"晚安"（最后一条她的话含晚安），这个目标的睡前主动消息自动跳过——避免"聊天里道过别、10分钟后又主动补一句晚安"的重复穿帮；按目标各查各的，A 道过了只发 B
- **1.2.0** **拟人分段发送**：主动消息按句切分逐条发（主动直发不经过聊天管线，此前多句挤一个气泡与聊天行为不一致）；条间隔按下一句长度模拟打字时间（每字 0.10~0.18 秒随机、0.8~8 秒夹取）——长句等得久，像真人输入，降低风控特征。开关 `dm_seg_enabled`；`/主动私聊测试` 同款
- **1.1.3** 目标解析改为**全部配置文件管理员并集**（配置绑定到具体会话时平台级探测看不到——同 bot 多配置场景，所有配置的管理员都是它的主人）；新增按 QQ 配称呼 `dm_alias_map`（"QQ=称呼"，多收信人各叫各的，避免对非主人也叫"主人"）
- **1.1.2** 新增**补发通道**：往插件数据目录写 `makeup.json`（`{"kind": "night"|"morning"|"random"}`，30 秒内被消费）即补发一条对应消息——绕过作息相位（管理员显式操作），仍受每日总量约束；晚安补发用专属提示词（"刚躺下才想起来没说晚安"），演出不穿帮
- **1.1.1** 修复记账bug：发送未成功（无目标/频控/异常）也会把晨起/睡前标记为已发导致静默吞掉——现在按真实发送结果记账，失败不销账、窗口内每30秒重试，连续3次失败才放弃
- **1.1.0** 生成附带聊天上下文：按目标会话取最近 N 条聊天记录（`dm_with_context` 开关、`dm_context_count` 条数）注入提示词，主动消息能接话茬；同时注入当前时间；改为按目标逐个生成（各自上下文）；`/主动私聊测试` 也走同款上下文
- **1.0.3** 管理员列表平台内去重（同平台重复填同一 QQ 不再重复发送）；跨平台同一 QQ 保持各发各的（各 bot 找各的主人）
- **1.0.2** 修复平台发现：`get_insts()` 返回列表而非字典（1.0.0 起平台解析一直失败，首条主动消息会静默跳过）；平台 ID 从 `config["id"]`/`meta().id` 取，跳过 webchat 控制台

## 工具调用（v1.3.0 已实现）

主动消息生成时可挂载**任意已注册的 llm_tool**（点歌、画图、搜索……装了什么用什么，不绑定具体插件）——模型按当轮心情与上下文自主决定是否使用（比如"放一首符合我现在心情的歌"）。**三类触发各自独立配置**，互不绑定：

| 触发 | 开关 | 白名单 |
|---|---|---|
| 晨起问候 | `dm_tools_morning_on` | `dm_tools_morning_names` |
| 睡前晚安（含补发） | `dm_tools_night_on` | `dm_tools_night_names` |
| 随机想念 | `dm_tools_random_on` | `dm_tools_random_names` |

- 白名单留空 = 该触发可用**全部**已注册工具；默认全关（纯文本，零额外成本）
- 实现走框架 `tool_loop_agent` + 合成事件（同 CronMessageEvent 先例）：副作用型工具（发卡片/图片类）会直接把结果发进目标私聊，返回值型工具的结果融进她的文本
- 工具轮超时 90s/整轮 150s，失败自动回落纯文本生成，最终文本照常拟人分段+归档
- 兼容性按工具而异（个别工具读不到合成事件的冷门字段会当轮失效不报错）——建议先小范围白名单实测再放开
